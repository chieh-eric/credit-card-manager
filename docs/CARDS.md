## 每個時間點要做的事

### 每月（月底前）
- [ ] **Amex Gold – Dining Credit $10**：Grubhub/Seamless、Five Guys、Cheesecake Factory、Buffalo Wild Wings、Wonder（需登記）
- [ ] **Amex Gold – Uber Cash $10**：自動進 Uber App，月底不用就沒了
- [ ] **Amex Gold – Dunkin' $7**（需登記）

### 每季（3/31、6/30、9/30、12/31 前）
- [ ] **Hilton Surpass – $50 Hilton credit**：直接向 Hilton 訂房，或在 Hilton 飯店餐廳/酒吧消費

### 每半年（6/30、12/31 前）
- [ ] **Amex Gold – Resy $50**：美國 Resy 合作餐廳（需登記）

### 每年 / 每開卡週年
- [ ] **Venture X – $300 Capital One Travel credit**（週年年度）
- [ ] **Sapphire Preferred – $100 Chase Travel hotel credit**（週年年度）
- [ ] **Marriott Boundless – 35k Free Night**：週年後入帳，12 個月內要用
- [ ] **Hilton Surpass – 日曆年消費 $15,000 → Free Night** ⚠️
- [ ] 年費入帳前一個月：評估要不要續卡 / 降級 / 打 retention

### 一次性
- [ ] **Sapphire Preferred – 2026/12/31 前啟用 DoorDash DashPass**

### 每 4 年
- [ ] **Global Entry / TSA PreCheck**：Sapphire Preferred 與 Venture X 各一次（可以幫家人付）

## 什麼情況刷什麼卡

點數價值以 MR/UR 2.0¢、C1 1.8¢、Hilton 0.5¢、Marriott 0.8¢ 估算（可在 App 設定調整）。

| 情況 | 首選 | 原因 |
|---|---|---|
| 美國餐廳 / 外送 | **Amex Gold** 4x | 8¢/$；先用 Gold 的 Dining/Resy/Dunkin' credit |
| 國外餐廳 | **Amex Gold** 4x | 全球餐廳都算，免手續費 |
| 美國超市 | **Amex Gold** 4x | 每年 $25k 上限；Target/Walmart/Costco 不算 |
| 線上買菜 (Instacart 等) | **Sapphire Preferred** 3x | |
| 加油 / EV 充電 | **Sapphire Preferred** 3x | 2026/6 新增 |
| 藥局 | **Freedom Unlimited** 3x | |
| 串流訂閱 | **Sapphire Preferred** 3x | |
| Airbnb / Vrbo | **Sapphire Preferred** 3x | 2026/6 新增 |
| Uber / Lyft / 交通 | Gold Uber Cash → **Sapphire Preferred** 2x | |
| Hilton 住宿 | **Hilton Surpass** 12x | 先用每季 $50 credit |
| Marriott 住宿 | **Marriott Boundless** 6x | |
| 其他飯店 / 機票直訂（要保險） | **Sapphire Preferred** 2x | 行程取消/延誤險、主要租車險 |
| 機票直訂（只看點數） | **Amex Gold** 3x | 但無航班延誤險 |
| 旅遊平台訂飯店/租車 | **Venture X** 10x（C1 Travel） | 先用掉 $300 credit |
| 旅遊平台訂機票 | **Sapphire Preferred** 5x（Chase Travel）或 Venture X 5x | |
| 租車 | **Sapphire Preferred** 或 Venture X | 兩張都是主要租車險 |
| 其他所有消費 | **Venture X** 2x | 3.6¢/$，比 Freedom Unlimited 1.5x 好 |
| 國外 / 外幣 | **Venture X** 2x | ❌ 不要用 Freedom Unlimited（3% 手續費） |
| 衝 Surpass $15k Free Night 時 | Hilton Surpass 3x | 一般消費暫時轉到 Surpass |

## 各卡詳細

### Amex Gold — 年費 $325
**回饋**：餐廳 4x（全球，每年 $50k 上限）｜美國超市 4x（$25k 上限）｜機票直訂/AmexTravel 3x｜AmexTravel 預付飯店 5x（2026/4/30 起）｜其他 1x

**Credits**
| 項目 | 金額 | 週期 | 備註 |
|---|---|---|---|
| Dining Credit | $10 | 每月 | Grubhub/Seamless、Five Guys、Cheesecake Factory、Buffalo Wild Wings、Wonder；需登記 |
| Uber Cash | $10 | 每月 | 美國 Uber/Uber Eats |
| Resy | $50 | 每半年 | 需登記 |
| Dunkin' | $7 | 每月 | 需登記 |

**其他**：The Hotel Collection（2 晚以上 $100 額度）、Hertz Gold+ Five Star、無海外手續費。
2026 改版移除 Goldbelly、Wine.com dining 合作商家；限時 Uber One $96 credit 已於 2026/10/30 結束。

### Chase Sapphire Preferred — 年費 $95
**回饋**（2026/6/15 改版後）：Chase Travel 5x｜餐廳 3x｜串流 3x｜線上買菜 3x｜**加油+EV 3x**｜**度假屋 (Airbnb/Vrbo) 3x**｜其他旅遊 2x｜其他 1x

**Credits**：Chase Travel 飯店 $100/週年年度（原本 $50）｜Global Entry/TSA/NEXUS $120/4 年（新增）

**其他**：DashPass（2026/12/31 前啟用）、Apple TV 相關權益 ⚠️、主要租車險、行程取消/延誤險、行李延誤險、緊急撤離保障（新增）。
**注意**：10% 週年點數加碼取消；⚠️ 有報導指 UR→Hyatt 轉點將變 4:3。舊持卡人新權益生效日請看帳戶公告（官方新聞稿提到 2026/10/1）。

### Chase Freedom Unlimited — 年費 $0
**回饋**：Chase Travel 5x｜餐廳 3x｜藥局 3x｜其他 1.5x。
**注意**：3% 海外交易手續費。點數合併到 Sapphire Preferred 可以轉點。

### Hilton Honors Amex — 年費 $0
**回饋**：Hilton 7x｜美國餐廳/超市/加油 5x｜其他 3x。Silver 會籍；年消費 $20k → Gold。
**策略**：Surpass 每一類都比它高，這張保留養信用歷史即可。

### Hilton Honors Amex Surpass — 年費 $150
**回饋**：Hilton 12x｜美國餐廳/超市/加油 6x｜美國網購 4x｜其他 3x
**Credits**：$50 Hilton credit 每季（$200/年，需直接向 Hilton 訂）
**其他**：Gold 會籍｜年消費 $40k → Diamond｜Priority Pass 每年 10 次｜日曆年消費 $15k → Free Night ⚠️

### Capital One Venture X — 年費 $395
**回饋**：C1 Travel 飯店/租車 10x｜C1 Travel 機票/度假屋 5x｜其他 2x
**Credits**：$300 Capital One Travel/週年年度｜每年 10,000 週年 miles｜Global Entry/TSA $120/4 年
**其他**：Capital One Lounge、Priority Pass、Hertz President's Circle、主要租車險、手機保險
**⚠️ 2026/2/1 起**：附卡貴賓室需 $125/年；主卡帶同伴需年消費 $75,000，否則同伴付費。

### Marriott Bonvoy Boundless — 年費 $95
**回饋**：Marriott 6x（含會籍最高 17x）｜超市/加油/餐廳 3x（合計每年前 $6,000）｜其他 2x
**Credits**：每週年一張 35k Free Night（可加 15k 自己點數，12 個月內有效）
**其他**：Silver Elite、15 晚 Elite Night Credits、每 $5,000 消費 +1 晚、年消費 $35k → Gold。
